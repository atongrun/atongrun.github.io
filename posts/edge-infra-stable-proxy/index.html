终于有了自己稳定的科学上网环境：edge-infra

23 Aug, 2026

成功！用自己购买的 VPS 部署了专属于自己的节点，独享！算是终于有了一个稳定的网络环境，Codex 稳稳的。

整体方案是 Codex 帮我做的，架构如下，Reality 作为主节点，深度用了一个月了很稳定：

Mihomo 主链路 fallback
  1. DediOne-Reality   VLESS + Reality + Vision   TCP 9443
  2. DediOne-Trojan    Trojan/TLS                TCP 8443
  3. DediOne-HY2       Hysteria2                 UDP 443
  4. DediOne-HY2-Hop   Hysteria2 port hopping    UDP 20000-20031 -> UDP 443

HTTPS subscription    nginx                    TCP 443
ACME challenge        nginx                    TCP 80

开源到了 GitHub：edge-infra，可以直接让 agent 去部署，有点稳定简单，不要面板，到时候就算换 VPS 也能把这行命令复制给 agent 让它一键帮我部署：

curl -fsSL https://raw.githubusercontent.com/atongrun/edge-infra/v0.1.0/docs/guide/installation.md

我订阅了 4 个机场，两个年包，每月固定流量，一个贵点，一年 100 多，但是只有 20G，另外一个年不到 15；两个固定流量包，一个 50 块钱 150G，另外一个忘了多少流量了可能有个 500G，也 10 块钱左右吧。

但是有段时间 4 个机场晚上每一个好使的，都不稳定时不时 timeout，我当时特别想买个稳定的小鸡部署一个科学上网的节点，我其实有一个 CloudCone 的机器，很便宜，一年不到 100，但是这个 VPS 没有线路优化，所以部署的节点也很卡～

然后有网络优化线路的 VPS，比如搬瓦工，DMIT，非常贵，一个月就上百，并且一般还没货，所以这个小心愿一直埋藏在心里。

很是机缘巧合，刷 X 刷到一个机器，联通和移动有线路优化的一个小鸡，我正好也是移动联通的环境，一年 200 多，一想可以有个稳定的自用 IP，线路正好合适，就直接拿下了：

DediOne 套餐，洛杉矶机房 $29.99/年（约 $2.5/月）：1C1G、10G NVMe、500GB/月流量、200Mbps 端口，平均延迟 207ms、0% 丢包；平均约 50Mbps。GitHub、Codex、Claude、Telegram、X 连通稳定，非常不错的小鸡。
